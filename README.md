# Wallis
Por Felipe Colli, Benjamin Bascuñan, Joaquín Pérez, Agustin Concha, Diego Alvarado

---

## Nuestro Proyecto
### Valores
- Responsabilidad Medioambiental
- Determinacion
- Compañerismo
- Autosuficiencia

### Tematica
Una playa limpia. Chile tiene casi 6500 kms de costa, y poseé aproximadamente 900 playas, de las cuales todas estan contaminadas con plasticos, basura y microplasticos

### Wallis
Nuestro poryecto es crear un robot autónomo, tipo tractor, que funcione de noche, y a través de la filtración de arena, sea capaz de remover plasticos y basura de las playas chilenas
